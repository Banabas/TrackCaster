TrackCaster

Eigenes OBS-Overlay für Traktor – läuft lokal, ohne Konto, ohne Abo.

Vorschau

Browserquelle in OBS: Breite 800 × Höhe 300 (gestrichelter Rahmen in der Vorschau).

Am Stream-PC muss dieser Rechner erreichbar sein. Beim ersten Start fragt das System nach eingehenden Verbindungen: erlauben (Windows: „Private Netzwerke"). Unter Windows hilft sonst firewall-freigeben.bat.

Einrichtung

  1. Traktor → Preferences → Broadcasting: Address localhost, Port 8000, Mount path /, Format Ogg Vorbis (11025 Hz / 32 kBit/s reicht).
  2. Im Traktor-Header auf das Broadcast-Symbol (Antenne) klicken, bis es dauerhaft leuchtet.
  3. In OBS eine Browserquelle anlegen, die URL oben einfügen, Breite und Höhe wie unter der URL angegeben.
  4. Zwei PCs: Programm auf dem DJ-PC starten (Traktor bleibt bei localhost). Oben „anderem PC" wählen und diese URL in OBS auf dem Stream-PC eintragen.
  5. Optional: Für eine reine Textquelle in OBS die Datei current-track.txt im Programmordner verwenden.
